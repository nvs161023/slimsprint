# Анкета предварительной заявки SlimSprint для Яндекс Форм

## Идея анкеты

Форма проверяет спрос, а не собирает данные для продукта. Поэтому в ней
только то, без чего нельзя связаться с человеком и понять, насколько он
заинтересован. Всё, что касается здоровья, веса и питания, из этой формы
исключено намеренно: медицинские сведения на этапе заявки не нужны и
повышают правовой риск.

Всего шесть экранов, около минуты на заполнение. Первый экран — самый
простой (имя), чтобы начать было легко.

## Структура

| № | Экран | Вопрос | Тип | Обязательный |
|---|-------|--------|-----|--------------|
| 1 | Контакт | Как к тебе обращаться? | Текст (1 строка) | Да |
| 1 | Контакт | Куда сообщить о запуске? | E-mail | Да |
| 1 | Контакт | Телефон или мессенджер | Телефон | Нет |
| 2 | О проекте | Откуда ты узнал(а) о SlimSprint? | Один вариант | Нет |
| 2 | О проекте | Часовой пояс | Выпадающий список | Нет |
| 3 | Интерес | Что для тебя важнее всего? | Один вариант | Да |
| 3 | Интерес | Что мешает наладить питание сейчас? | Несколько вариантов | Нет |
| 4 | Согласия | Согласие на обработку данных | Чекбокс | Да |
| 4 | Согласия | Согласие на сообщения о запуске | Чекбокс | Нет |

## Экран 1. Контакт

**Заголовок:** Познакомимся

**Описание:**

> Оставь контакты — напишем, когда программа будет готова. Это
> предварительная заявка: оплата не взимается, обязательств она не
> создаёт.

**Поле 1**
- Подпись: `Как к тебе обращаться?`
- Тип: текст, одна строка
- Подсказка в поле: `Имя`
- Обязательное: да
- Ограничения: до 60 символов

**Поле 2**
- Подпись: `Куда сообщить о запуске?`
- Тип: e-mail
- Подсказка в поле: `name@example.com`
- Обязательное: да
- Ошибка валидации: `Проверь адрес — кажется, в нём опечатка`
- Пояснение под полем: `Пришлём одно письмо о запуске. Рассылок не будет.`

**Поле 3**
- Подпись: `Телефон или мессенджер`
- Тип: телефон
- Подсказка в поле: `+7 900 000-00-00 или @username`
- Обязательное: нет
- Пояснение под полем: `Необязательно. Нужен, только если удобнее получить сообщение, а не письмо.`

**Разделитель после экрана:** переход к следующей странице.

## Служебные поля (скрытые)

Эти поля не показываются посетителю, но нужны для аналитики.

| Техническое имя | Подпись | Тип | Источник |
|---|---|---|---|
| `utm_source` | источник | скрытое / текст | из адреса страницы |
| `utm_medium` | канал | скрытое / текст | из адреса страницы |
| `utm_campaign` | кампания | скрытое / текст | из адреса страницы |
| `utm_content` | объявление | скрытое / текст | из адреса страницы |
| `utm_term` | ключевое слово | скрытое / текст | из адреса страницы |
| `form_version` | версия анкеты | скрытое, `2026-11-26` | константа |
| `consent_version` | версия согласия | скрытое, `1.0` | константа |

В Яндекс Формах UTM удобно передавать через параметр `activetab` или
через скрытые поля, заполняемые скриптом страницы. Это настраивается
после создания формы.

## Что намеренно НЕ спрашиваем

| Вопрос | Почему нет |
|---|---|
| Вес, рост, возраст | Это продукты анкеты программы, а не заявки. Собирать их сейчас не нужно и рискованно |
| Цель по весу | Прямая связь с медицинской оценкой, которую заявка не покрывает |
| Аллергии и ограничения | Требует продуктового алгоритма и контроля качества |
| Заболевания | Специальная категория данных, для заявки не нужна |
| Бюджет | На этапе проверки спроса портит честность ответа |

## Как создать в Яндекс Формах

1. Откройте https://forms.yandex.ru и создайте новую форму.
2. Заголовок: `SlimSprint — предварительная заявка`.
3. Включите постраничный показ (`Настройки → Разделы`) и создайте четыре раздела с заголовками из этой анкеты.
4. Перенесите поля из таблицы выше в том же порядке.
5. Поля с несколькими вариантами — тип `Несколько вариантов`.
6. Включите `Проверка ответов` для обязательных полей.
7. В `Настройки → Кнопка отправки` укажите текст `Оставить заявку`.
8. Настройте ссылку на политику в тексте согласия.
9. В `Настройки → После отправки` выберите `Показать текст` и вставьте текст экрана благодарности.
10. Уведомления: включите письмо на `nvs16@ya.ru`.
11. Опубликуйте форму и скопируйте ссылку вида `https://forms.yandex.ru/u/...`.
12. Эту ссылку впишите в `docs/assets/lead-config.js`:

```js
window.SLIMSPRINT_FORM = {
  yandexFormUrl: "https://forms.yandex.ru/u/ВАШИДЕНТИФИКАТОР/"
};
```

После этого кнопка на сайте сразу начнёт вести в форму, менять HTML не
придётся.

## Проверка перед запуском

- [ ] Форма открывается с телефона и с компьютера.
- [ ] Обязательные поля блокируют отправку.
- [ ] Чекбокс согласия обязателен, чекбокс сообщений — нет.
- [ ] Ссылки на политику и согласие открываются.
- [ ] Письмо-уведомление приходит на `nvs16@ya.ru`.
- [ ] UTM из рекламы попадают в ответы.
- [ ] Экран благодарности показывается после отправки.
