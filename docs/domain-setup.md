# Привязка домена slimsprint.ru к GitHub Pages

Домен оформлен в reg.ru (NS: `ns1.reg.ru`, `ns2.reg.ru`). A-записей пока
нет, поэтому адрес не открывается. Ниже — что сделать, когда будем
привязывать.

## 1. DNS в панели reg.ru

Раздел «Домены → slimsprint.ru → DNS-серверы и управление зоной»:

| Тип | Имя | Значение | TTL |
|-----|-----|----------|-----|
| A | `@` | `185.199.108.153` | 3600 |
| A | `@` | `185.199.109.153` | 3600 |
| A | `@` | `185.199.110.153` | 3600 |
| A | `@` | `185.199.111.153` | 3600 |
| CNAME | `www` | `nvs161023.github.io.` | 3600 |

Проверка (через 10–30 минут):

```sh
nslookup slimsprint.ru 8.8.8.8
nslookup www.slimsprint.ru 8.8.8.8
```

## 2. Файл CNAME в репозитории

Создать `docs/CNAME` с одной строкой без протокола:

```
slimsprint.ru
```

GitHub Pages перенесёт опубликованный адрес на домен и включит HTTPS для
него автоматически (сертификат Let's Encrypt, обычно 15–60 минут).

## 3. Настройка в GitHub

`Settings → Pages → Custom domain` → `slimsprint.ru` → Save →
дождаться статуса «DNS check successful» → включить `Enforce HTTPS`.

## 4. После переключения

Заменить ссылку на сайте в `docs/assets/lead-config.js`, если она там
используется, и проверить:

- `https://slimsprint.ru/` открывает лендинг;
- `https://slimsprint.ru/privacy-policy.html` открывает политику;
- форма Яндекса ведёт на эти же адреса;
- `http://` перенаправляется на `https://`.

## Пока домен не привязан

- В форме Яндекса ссылки на политику и «Вернуться на сайт» ведут на
  `slimsprint.ru`, который не открывается.
- В коде сайта `canonical` и `og:url` указывают на `slimsprint.ru`.
- Пока это не исправлено, рекламу не запускать: неработающая ссылка на
  политику — типичная причина отклонения объявлений.

## Вариант на время ожидания

Держать отдельную страницу-заглушку `soon.html` на GitHub Pages и
направить форму туда:

- политика: `https://nvs161023.github.io/slimsprint/privacy-policy.html`
- «Вернуться на сайт»: `https://nvs161023.github.io/slimsprint/`

После привязки домена поменять обратно на `slimsprint.ru`.
